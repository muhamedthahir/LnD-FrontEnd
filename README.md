# CodeAssess - Coding Assessment Platform

A modern React-based coding assessment platform for Learning & Development.

## Features

- 🔐 **Secure Authentication** - Email/password login with form validation
- 🎨 **Modern UI** - Dark theme with beautiful animations
- 📱 **Responsive Design** - Works on all devices
- 🔜 **SSO Ready** - Prepared for Google and GitHub OAuth integration

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Navigate to the project directory
cd LnD-FrontEnd

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`
